# Nyay Setu – AI Legal & Emergency Assistant

Nyay Setu is an AI-powered legal and emergency assistance platform built using the MERN stack. The platform helps users access legal guidance, emergency support, and AI-driven assistance through an intuitive and responsive interface.

## Features
- AI-powered legal guidance chatbot
- Emergency assistance support
- Full-stack MERN application
- Responsive and intuitive user interface

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **AI:** OpenAI integration

## Getting Started

### Prerequisites
- Node.js installed
- MongoDB instance (local or cloud)

### Installation
1. Clone the repository
git clone https://github.com/Jaya-Rajvanshi/ai-legal-assistant-platform.git
2. Install backend dependencies
cd backend
npm install
3. Install frontend dependencies
cd ../frontend
npm install
4. Set up environment variables (see `.env.example` in backend folder)
5. Run the backend
cd backend
npm start
6. Run the frontend
cd frontend
npm start

## Project Structure
- `backend/` — Express server, API routes, database models
- `frontend/` — React application
